# Repository instructions

Write all repository content in English, including documentation, code comments, commit messages, issues, and pull requests.

Use `dev` for development and testing. Promote verified changes to `main`. Preserve the approved golden executable until a replacement has passed Windows and NDI validation.


Use direct, natural technical writing. Do not mention the project owner or private conversations in project documentation. Put a prominent direct EXE download link at the top of release notes.
