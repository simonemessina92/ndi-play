# NDI PLAY 1.0 Gold

## [Download NDI PLAY.exe — Windows x64](https://github.com/simonemessina92/ndi-play/raw/b844eebf9483daecaf46f02e1a9e61478afe39c9/dist/NDI%20PLAY.exe)

**October 7, 2026** · Single portable EXE · VLC 3 x64 and the official NDI VLC Plugin required.

### Features

- Drag and drop local videos to create independent NDI sources.
- Loop each source automatically.
- Use the first audio track with its native channel layout.
- Add files to the running instance.
- Remove individual sources or stop all players from the tray menu.
- Run each source in a separate worker process.

### Playback

Sources loop independently. Playback is not synchronized between files, and seamless loop transitions are not guaranteed.

### Requirements

Windows x64, installed VLC 3.x x64, and the official NDI VLC Plugin in the same VLC installation. VLC and NDI dependencies are not bundled.
